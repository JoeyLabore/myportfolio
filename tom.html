Project Background

This was an internal Endava project for the Innovation Lab. TOM is an AI-driven DevOps automation tool that simplifies the journey from code to cloud.


The brand draws inspiration from the tension of Tom and Jerry, where intelligence outmaneuvers chaos. However, in this story, TOM wins. TOM represents focus, agility, and smart execution. The identity balances playfulness with precision to make DevOps feel fun, welcoming, & accessible.


  • Client: Endava
  • Type of work: Branding
  • Date: 2023
  • My Role: Visual Design Lead

Problem & Solution

Problem

Traditional software delivery models create bottlenecks across coding, testing, and deployment, leading to extended build phases, reduced scope flexibility, and strained client engagement.


Solution

TOM automates key build-stage activities by transforming feature inputs into executable development tasks, including code scaffolding, automated tests, and deployment setup, significantly shortening implementation time while maintaining quality standards. I focused on making DevOps more approachable and friendly, enabling more team members to confidently engage in processes traditionally seen as highly technical.
